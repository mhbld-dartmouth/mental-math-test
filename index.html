Mental Math Assessment

A five minute arithmetic task. Answer as many questions as you can before the time runs out.

5 minTime limit
100Maximum questions
4Choices per question

Instructions

Questions cover addition, subtraction, multiplication, division, squares, percentages and mixed arithmetic.

Select one answer for each question. Correct answers receive +1 point, incorrect answers receive −1 point and unanswered questions receive 0 points.

Use the mouse or keyboard keys A, B, C, D or 1, 2, 3, 4 to choose an answer. You can skip a question without penalty.

The countdown begins when you select Start assessment.
